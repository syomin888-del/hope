# Аудит семи требований

| Требование | Результат | Строгая граница |
|---|---|---|
| 1. Крипта / 3% в день | Причины отрицательного backtest видны; создана автоматическая OOS-проверка 4 новых заранее заданных гипотез | 3% ежедневно **не достигнуты** и не могут быть обещаны; нет реальной ликвидности/order-book исполнения |
| 2. Анализ каждого спортивного события | Все котируемые события получают статус исследования, вероятности только при достаточной истории и пройденной проверке | Для всех видов спорта пока нет надежных данных и универсальной математической модели |
| 3. Global Sports universe: load failed | Новый V7 центр не зависит от старого проблемного `/api/universe`; в старом маршруте явная диагностика ошибки | Корень конкретной ошибки старого не передан (нет запроса/traceback), старый интерфейс доступен для проверки |
| 4. Противоречащие ставки | Контроль уникального `root_id` в v56 портфеле + явный аудит, максимум $10 на событие | Конкурирующие исследовательские гипотезы остаются вне портфеля |
| 5. NO_VERIFIABLE_BOOKMAKER_ROI_FOR_OFFICIAL_SIGNALS / NO_SETTLED_PROSPECTIVE_SPORTS_FORECASTS | Скорректирована привязка scorecard к современной бумажной бухгалтерии, статусы ожидания итогов | Реального ROI или рассчитанного WIN/LOSS до финалов не появится |
| 6. Все источники «Ожидает» | Свежесть Fonbet и крипты берется из БД, UI показывает реальные причины неготовности | Нельзя сообщать «работает», если источник устарел или не подключён |
| 7. OpenAI/Claude/Gemini/CatBoost/XGBoost/PyTorch «План» | Проверяемые статусы и безопасный API health-probe, Elo/FORM/Poisson OOS | Нет ключей и обученных артефактов для платных LLM и CatBoost/XGBoost/PyTorch; выдавать «активно» было бы ложью |

Никакие новые реальные ордера не создаются. Все старые 405+ экспериментов и 7+ портфельных сигналов сохраняются. Проспективная прибыль не подменяется историческими результатами. Тесты проведены на локальных фикстурах, не на VPS.
