# ORACLE V5.5 — аудит доступной кодовой базы

**Область аудита:** локально доступны архивные исходники 35 Python-модулей на 23 октября, файлы релизов V5.0—V5.4 и предоставленные пользователем реальные JSON-логи V5.3. Нет подключённой текущей файловой системы работающего VPS, поэтому нет оснований утверждать, что проверена каждая строка всех фактических файлов, изменявшихся непосредственно на сервере. Проверка на сервере — обязательная часть процесса установки.

## Испытания в этой среде

- `python -m py_compile`: 35 архивных Python-модулей — синтаксически корректны (не функциональный сертификат).
- `python -m unittest discover -s tests -p 'test_*.py' -q`: локальный набор V5/V5.1/V5.2/V5.3/V5.4 + V5.5, реестр $10, расчёты WIN/LOSS/PUSH, изоляция старой ложной связи, архив предматчевых цен, проверка инсталлятора.
- `node --check`: JS интерфейса `/v5` прошёл синтаксическую проверку.
- Синтетическое испытание очереди 2 400 событий: 48 циклов по 48 событий => 2 304 попытки за 24 часа. Пропускная способность *настоящего* RSS и VPS этими тестами не подтверждена.

## Что НЕ проверено / не решено

1. 100% соответствие рыночных кодов Fonbet; значительная доля кодов остаётся непрозрачной.
2. Полные достоверные составы, травмы, психофизическое состояние каждого участника каждого события.
3. Работа сети/ресурсов Docker VPS после установки, фактическое время обновления всех источников и завершённость чужих матчей.
4. Прогнозы по каждому виду спорта (извлечение полной букмекерской линии НЕ тождественно умению прогнозировать все исходы).
5. Доказанное положительное математическое ожидание/реализованный ROI на независимых проспективных данных.

## Интерпретация ROI

Фиксированные гипотетические $10 назначаются не всем полученным строкам, а только **предварительно зафиксированным** выборам с документированным коэффициентом и `p*odds-1≥0` и odds≥1.7. Это эксперимент по сырым оценкам ORACLE, а не правило прибыльного отбора. Несколько рынков на одном матче статистически зависимы. Результат считается только по доступному финальному счёту из известных источников; неподдерживаемые рынки не засчитываются ни победой, ни поражением.
