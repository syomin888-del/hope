# ORACLE CORE v0.7 (базовая документация) — автономная исследовательская лаборатория

**Состояние на 20 октября 2026:** реальное локальное программное ядро с независимым сбором данных, постепенной загрузкой архива, статистическим обучением, строгой исторической проверкой и виртуальными прогнозами. **Не** готовая система прибыльных сигналов. Ни одной модели нельзя считать доказанно прибыльной без реальных данных и будущих результатов.

## Что уже существует и чего пока нет

**Есть:** 15 источников/задач сбора (включая 3 дополнения по рынку деривативов в одной задаче), сохранение исходных данных и времени получения, SQLite WAL, повтор после сбоев, постепенная загрузка месячных архивов Binance для BTC/ETH/SOL с 2017/2020 гг. до последнего опубликованного месяца, market-consensus для букмекерских коэффициентов (только информация), три варианта ML-модели на каждый из 9 криптосценариев, обособленная хронологическая калибровка и holdout, Brier score, сравнение с базовой моделью, интервальная оценка, журнал виртуальных прогнозов и их результатов, veto при ухудшении качества, мониторинг, локальные резервные копии, веб-интерфейс.

**Нет:** автоматического размещения ставок или сделок, обещанной гарантии выигрыша, реально подтверждённых прибыльных моделей, исторического массива букмекеров за 20 лет, прогнозирования всех видов спорта и всех монет, глубокого NLP-анализа всех новостей, платных LLM API. Это исследовательское ядро, которое можно постепенно развивать на данных.

## Как установить на Mac — один раз

1. Установи Python 3.10+ (если ещё нет) и распакуй архив. Python 3.12 или 3.13 предпочтительнее.
2. В Терминале перейди в каталог с `install_mac.sh`. Например:

```bash
cd ~/Downloads/ORACLE_CORE_v07
bash install_mac.sh
```

3. Установщик создаст виртуальное окружение, установит бесплатные Python-библиотеки `numpy` и `scikit-learn`, создаст базу и зарегистрирует **три фоновые службы** через macOS LaunchAgents: сборщики источников, исследователь и локальная веб-панель.
4. Открой **http://localhost:8765/#intelligence**.

Mac должен быть включён, не спать и иметь интернет. Если ноутбук уснул, процессы возобновляются при пробуждении; настоящая независимость от ноутбука требует сервера.

> Архивы загружаются постепенно — по шесть файлов в час, а не сотнями запросов сразу. Отсутствие сигнала в начале нормально и не является ошибкой.

**Проверить:**

```bash
./.venv/bin/python doctor.py
./.venv/bin/python brain_daemon.py status
./.venv/bin/python research.py status
```

**Остановить (не удаляя историю):**

```bash
bash uninstall_mac.sh
```

## Необязательные бесплатные ключи

В `.env` можно указать `ORACLE_NBA_KEY`, `ORACLE_ODDS_KEY`, `ORACLE_COINGECKO_KEY`, `ORACLE_FRED_KEY` по образцу `.env.example`. Без них продолжают работать публичные источники. Настя и Telegram **не подключаются**, все реальные сделки **отключены**.

```bash
cp .env.example .env
open -e .env
```

Не передавай торговые ключи, пароли или платёжную информацию. Работа со спортивными данными должна соответствовать условиям источника и применимому законодательству. Не запускай реальные онлайн-ставки в местах, где они запрещены.

## Что происходит само

| Процесс | Частота | Что делает |
|---|---|---|
| Публичные котировки/стаканы | Каждые 15–60 минут | Сохраняет снапшоты и закрытые свечи |
| Новости / DeFi / макро / спорт | От 6 часов до суток | Независимые адаптеры, лог ошибок |
| История Binance 1h | 6 архивов в час | Дополняет доступную историю; избегает повторов |
| Обучение 9 задач крипты | Раз в сутки | Логистическая регрессия, лес и бустинг, выбор по отложенной калибровке |
| Виртуальные прогнозы | Ежечасно | Только для прошедших **историческую** проверку моделей |
| Проверка результатов | Каждые 30 минут | Находит закрытую свечу на сроке прогноза; не подгоняет результат |
| Проверка новых ошибок | При каждом прогнозе | Отключает ухудшившиеся модели |
| Локальная резервная копия | Раз в неделю | SQLite snapshot с тремя последними копиями |

**Важно:** выигрыши и доходность не будут возникать от количества проверенных гипотез. Все статистические улучшения проходят независимый holdout и последующий новый период. Прогнозы не «переделываются» после исхода.

## Что представляет собой исследователь

- Задачи: вероятность роста на **2% за 6 часов**, **5% за 24 часа**, **10% за 72 часа**. Это заранее заданные проверяемые вопросы, не обещание будущего роста.
- Для каждой валюты используется до 12 исторических признаков: доходность на разных интервалах, волатильность, объёмы, диапазоны, ускорение и другие признаки, рассчитанные исключительно по **завершённым** свечам.
- Учитываются только независимые неперекрывающиеся исходы; требуются минимум 550 независимых размеченных случаев.
- Данные делятся строго по времени: обучение ~64%, калибровка ~15%, финальная ранее не увиденная проверка ~21%, разделы очищаются от временных пересечений.
- Сравнение: Brier score против базовой частоты исхода на обучении; нижняя граница улучшения при ресэмплинге; устойчивость на двух половинах финальной выборки.
- Если подтверждение не получено, состояние **REJECTED** или **WAIT_DATA**. Если получено — **HISTORICAL_PASS_SHADOW**, но это всё ещё не торговый сигнал.
- После накопления новых прогнозов ORACLE сравнивает их с базовым прогнозом; при ухудшении прекращает генерацию.

Обучение моделей **не доказывает причинно-следственную связь**. Исследуемые временные горизонты могут быть слишком короткими, а рынок может быть непредсказуем. Даже положительные исторические тесты не гарантируют прибыль.

**Спорт:** в этой версии реализованы сбор и нормализованная рыночная оценка без маржи букмекеров по поддерживаемым событиям. Обученного независимого спортивного прогнозиста **нет**. Бесплатного набора архивных odds, injuries и point-in-time news для полного 20-летнего теста тоже нет. Спорт намеренно **не предлагает ставки**, пока не построена и не проверена отдельная модель.

## Если нужен сервер 24/7

При наличии **твоего** Linux-сервера с Docker / Compose:

```bash
mkdir -p logs model_artifacts
# .env необязателен
docker compose up -d --build
docker compose ps
```

Веб-панель публикуется **только на 127.0.0.1** сервера. Для доступа с Mac по SSH (при наличии серверного логина):

```bash
ssh -L 8765:localhost:8765 USER@YOUR_SERVER
```

Открой http://localhost:8765/#intelligence на Mac. Никогда не выставляй локальную панель без авторизации в публичный интернет.

Для сервера оплата VPS начинается только после твоего явного выбора тарифа. Этот проект **не может самостоятельно оплатить и развернуть сервер** без предоставленного доступа.

## Ограничения источников и стоимости

- The Odds API: бесплатные живые коэффициенты по лимиту аккаунта; исторические коэффициенты — **платные**, что подтверждено документацией провайдера.
- Binance Data: открытые архивы; доступны не для всех активов и периодов, региональные ограничения возможны.
- FRED: данные пересматриваются — для ретроспективных прогнозов потребуются винтажи ALFRED / реальные даты публикаций.
- CoinGecko Demo и другие провайдеры: квоты, доступность и лицензии ограничивают объём.
- Football-Data: запрещено использовать массовое автоматизированное скачивание бесплатных файлов для коммерческого обучения без согласования.
- LLM API **не включены** по умолчанию и не расходуют деньги. Прежде чем их добавлять, необходимо показать, что извлечение фактов из источников улучшает holdout качество.

## Тесты и структура

```bash
./.venv/bin/python -m unittest discover -s tests -v
```

`collect.py` / `sources.py` — первичные источники и исторические снапшоты; `backfill.py` — постепенный архив; `market.py` — описание коэффициентов; `research.py` — обучение и paper-прогнозы; `brain_daemon.py` — исследовательское расписание; `daemon.py` — расписание источников; `doctor.py` — диагностика; `backup.py` — резервные копии; `dashboard.py` / `index.html` — веб-панель; `oracle.py` — старый строгий реестр внешних прогнозов (автоматическая отправка по умолчанию выключена).

Весь проект создаётся для анализа/обучения, а не для обещания результатов. Самообновление не означает, что код и внешние API никогда не потребуют изменений.
