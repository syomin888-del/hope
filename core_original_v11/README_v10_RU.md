# ORACLE v1.0 — наблюдаемость и запуск

Создано поверх проверенного ORACLE v0.9. Исходная функция прогнозирования не изменена; не добавлены платные источники, ставки или реальная торговля.

## Что нового

- `telemetry.py`: честный посуточный отчёт по фактически записанным источникам, свечам, гипотезам, виртуальным прогнозам, сигналам и результатам. Календарный день — Asia/Makassar (Бали), по времени фактической записи в SQLite.
- Heartbeats от процессов `daemon.py run` (источники) и `brain_daemon.py run` (аналитика). Процесс считается активным, только если за последние пять минут получен его heartbeat; давние записи не считаются живой системой.
- `/api/telemetry` и страница «Сводка за сегодня» в ORACLE dashboard.
- `tests/test_telemetry.py` проверяет границы суток, уникальность событий, отсутствие придуманных сигналов, сбои источников и остановку процессов.
- `upgrade_from_v09.py`: безопасное копирование старой SQLite-базы, `.env` и моделей без перезаписи. Старая папка не меняется.
- `compose.yaml`: данные, резервные копии, логи и модели хранятся вне контейнера. Веб-панель доступна на сервере только через `127.0.0.1`, не на весь интернет.

**Важно:** посуточное число наблюдений не отражает число «проанализированных вероятностей». Исторически проверенные криптомодели v0.9 являются лишь виртуальными и **не** сертифицированы для реальной торговли. Для спорта нет подтверждённой прогностической модели. Ноль записей в существующей БД — это ноль, а отсутствие БД — «неизвестно».

## Если на Mac ничего ещё не было установлено

Распакуй ZIP, перейди в папку `ORACLE_CORE_v10`, запусти:

```bash
bash install_mac.sh
python3 telemetry.py
```

Требуется Python 3.10+. Панель: `http://localhost:8765/#telemetry`.

## Если Mac уже запускает v0.9

Останови старые службы и **не удаляй старую папку**:

```bash
cd ~/Downloads/ORACLE_CORE_v09
bash uninstall_mac.sh
cd ~/Downloads/ORACLE_CORE_v10
python3 upgrade_from_v09.py --from ~/Downloads/ORACLE_CORE_v09
bash install_mac.sh
python3 telemetry.py
```

`upgrade_from_v09.py` откажется от перезаписи существующей базы назначения. При нестандартном расположении папок замени пути.

## Запуск 24/7 на своём Linux VPS (оплата и доступ к серверу отдельно)

1. Нужен VPS с доступом SSH, Docker и Docker Compose v2. ORACLE **не развёрнут автоматически**: этот архив лишь подготовлен к запуску.
2. Перенеси **всю** папку `ORACLE_CORE_v10` на сервер по защищённому соединению. Никогда не присылай `.env` или SSH-ключи в чат.
3. Перейди в директорию проекта на сервере:

```bash
mkdir -p logs model_artifacts backups
# Необязательные API-ключи устанавливаются в .env (chmod 600)
docker compose up -d --build
# Фактические данные, а не предполагаемые показатели:
docker compose exec -T research python telemetry.py --json
# Статус процессов:
docker compose ps
```

Для доступа к **непубличной** панели с Mac через SSH-туннель:

```bash
ssh -L 8765:127.0.0.1:8765 USER@YOUR_SERVER
```

После этого открой на Mac `http://localhost:8765/#telemetry`.

Не публикуй порт 8765 на публичном IP: здесь нет встроенной авторизации. Для публичного доступа в будущем нужен полноценный reverse proxy с TLS и аутентификацией.

## Отчёты и контроль

```bash
python3 telemetry.py                     # сегодня, WITA
python3 telemetry.py --date 2026-10-21  # конкретные сутки
python3 telemetry.py --json              # машинный JSON
python3 daemon.py status                 # источники
python3 brain_daemon.py status           # модели и расписание
python3 -m unittest discover -s tests -q
```

Если `notifications_enabled=false` в настройках автоматизации ChatGPT, исправляется в приложении пользователем: ORACLE не умеет менять настройки уведомлений ChatGPT из собственного кода.

## Известные ограничения

- Счётчики не доказывают эффективность прогнозов. Допущенных к денежным операциям моделей нет.
- Сервис Research Watch внутри ChatGPT и SQLite-история ORACLE **разные системы**. Пока нет подключённого центрального сервера/API, нельзя суммировать или утверждать их общее количество обработанных новостей.
- Бесплатные API могут блокировать регион, вводить квоты или менять формат. Журнал покажет ошибки, а не молча выдаст нули.
- Docker-сборка и удалённый деплой требуют инфраструктуры пользователя. Без сервера ORACLE может работать локально на включённом Mac.
- Входящие котировки не всегда доступны для исполнения по историческим ценам. Не трактуй виртуальный EV как гарантированную прибыль.
